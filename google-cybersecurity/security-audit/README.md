# Security Audit – Botium Toys

## Overview

This security audit was completed as part of the Google Cybersecurity Professional Certificate. The assessment focused on identifying security control gaps, compliance issues, and recommendations for improving the security posture of Botium Toys, a fictional company.

## Controls Assessment

The assessment identified several controls that were not currently implemented, including:

- Least privilege
- Disaster recovery plans
- Separation of duties
- Intrusion detection system (IDS)
- Backups
- Encryption
- Password management system
- CCTV surveillance
- Fire detection/prevention

Some controls were already in place, including password policies, firewalls, antivirus software, legacy system monitoring, and physical locks.

## Compliance Assessment

The assessment also identified gaps related to:

### PCI DSS
- Unauthorized access to customer credit card information
- Secure handling of payment card information
- Encryption of payment card data
- Secure password management

### GDPR
- Protection of EU customers' data
- Data classification and inventory
- Privacy policies and procedures

### SOC
- User access policies
- Protection of sensitive PII/SPII

## Recommendations

Multiple controls should be implemented to improve Botium Toys’ security posture and protect sensitive information. The highest priorities should include implementing least privilege, separation of duties, encryption, and a password management system. These controls would help reduce the risk of unauthorized access and better protect sensitive PII, SPII, and customer payment information.

Botium Toys should also implement disaster recovery plans and regular backups to help the organization recover from data loss, system failures, or security incidents. An intrusion detection system (IDS) should also be considered to improve the organization’s ability to detect potential security threats. In addition, properly classifying and inventorying data would help the organization identify sensitive information and determine which additional controls are needed to protect it.
